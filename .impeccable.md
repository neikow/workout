## Design Context

### Users
Solo developer/gym-goer (French), uses the app in-gym on mobile during active training. Mobile-first. Values speed and zero friction — the phone is out for 10 seconds max per set logged.

### Brand Personality
Spare, tactical, habitual. Like a paper training log that knows what you're going to write. Not a "fitness app" — no gamification, no charts, no social. A sharp tool.

### Aesthetic Direction
Monospace-forward editor chrome. Minimal UI shell that gets out of the way of the text. Indigo accent is established and should stay. Dark mode is primary (gym lighting), but explicit theme control is offered. No rounded-corner card grids, no hero layouts, no glassmorphism.

### Design Principles
1. **Invisible chrome** — UI elements should whisper, not shout. The text IS the app.
2. **Keyboard/thumb efficiency** — every tap is one thumb, at arm's length, mid-set.
3. **Consistent density** — tight spacing in the editor, slightly more generous in settings (one-time task).
4. **Theme fidelity** — Monokai means REAL Monokai syntax colors mapped to workout types.
5. **No decoration for decoration's sake** — every visual element serves a functional purpose.
